2. [P3] Three noVNC waits ignore their explicit timeout values.

   Location: `docs/research/computer-chrome-linux/check-vnc.mjs:255`, also lines 263 and 290.

   Playwright's signature is `waitForFunction(pageFunction, arg, options)`. These calls supply `{ timeout: ... }` in the second slot. The installed library serializes that object as the page-function argument and uses its default 30,000-ms timeout. A failed authentication or framebuffer condition therefore waits 30 seconds instead of the intended 12 or 15 seconds, consuming more of the container's 90-second VNC hold budget. This remains bounded under normal defaults and does not itself produce a false pass.

   Reproduction: `node /tmp/nap-round2-timeout-repro.cjs`. No browser is launched. Captured parameters are in `/tmp/nap-round2-timeout-repro.json`.

   Smallest repair: pass `undefined` as the second argument and the timeout object as the third argument in all three calls.
